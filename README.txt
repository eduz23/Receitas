# Quick Fit — página recriada

Arquivos:
- index.html
- style.css
- script.js

## Antes de publicar
1. No `index.html`, substitua `CAKTO_CHECKOUT_URL` pelo seu checkout da Cakto.
2. Os 3 order bumps devem ser configurados no checkout da Cakto:
   - 50 Doces Fitness — R$ 7,90
   - Cardápio Fitness de 14 Dias — R$ 9,90
   - Guia de Organização de Marmitas — R$ 6,90
3. A seção de depoimentos está deliberadamente preparada como placeholder. Não publique fotos/nome/depoimentos como se fossem clientes reais sem que sejam reais e autorizados.
4. As imagens de alimentação usam imagens externas de demonstração. Você pode substituí-las pelas imagens do seu material.

A página foi recriada com HTML/CSS/JS próprios, usando a estrutura pública da página de referência como inspiração; não é uma cópia do código interno da aplicação original.
